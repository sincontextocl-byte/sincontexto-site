Política de Privacidad

Última actualización: 24 de septiembre de 2026.

1. Finalidad

SinContexto Publisher se utiliza para conectar cuentas autorizadas del proyecto SinContexto con plataformas sociales y gestionar la publicación de contenido mediante sus APIs oficiales.

2. Datos tratados

La aplicación puede recibir identificadores de cuenta, permisos de autorización y tokens de acceso necesarios para utilizar las funciones autorizadas por el usuario.

3. Uso de la información

La información se utiliza únicamente para autenticar la cuenta autorizada y ejecutar las acciones solicitadas, como la publicación de contenido.

4. Almacenamiento

Los tokens y datos técnicos necesarios para la integración se almacenan de forma privada en la infraestructura local utilizada por el propietario de SinContexto. No se publican en este sitio web.

5. Compartición

SinContexto Publisher no vende información personal. Los datos solo se comunican a las plataformas correspondientes cuando es necesario para utilizar sus APIs y servicios.

6. Revocación

El usuario puede revocar el acceso otorgado a la aplicación desde las opciones de seguridad o aplicaciones conectadas de la plataforma correspondiente.

7. Contacto

Para consultas relacionadas con privacidad, utiliza el canal de contacto público asociado al proyecto SinContexto.
