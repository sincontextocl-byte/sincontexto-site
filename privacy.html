Política de Privacidad

Última actualización: 24 de septiembre de 2026.

1. Finalidad

SinContexto Control Center es una herramienta utilizada para producir, organizar, publicar y analizar contenido del proyecto SinContexto. Algunas funciones utilizan YouTube API Services y Google OAuth 2.0.

2. Datos de YouTube y Google a los que podemos acceder

Cuando el usuario autoriza la integración, la aplicación puede acceder únicamente a la información y permisos incluidos en los scopes de OAuth aprobados, como información básica del canal, gestión de videos autorizada y datos necesarios para consultar el estado o rendimiento del contenido.

3. Uso de la información

La información obtenida mediante YouTube API Services se utiliza únicamente para ofrecer las funciones solicitadas por el usuario, como subir contenido, actualizar metadatos, consultar publicaciones y mostrar estadísticas dentro del Control Center.

4. Almacenamiento

SinContexto Control Center puede almacenar localmente identificadores técnicos, estados de publicación, URLs, metadatos del contenido y tokens de autorización necesarios para mantener la integración. No almacenamos contraseñas de Google o YouTube.

5. Compartición

No vendemos datos personales ni datos obtenidos mediante YouTube API Services. La información se comunica a Google/YouTube únicamente cuando es necesario para ejecutar las funciones autorizadas por el usuario.

6. YouTube API Services y políticas de Google

SinContexto Control Center utiliza YouTube API Services. Al utilizar las funciones conectadas a YouTube, también se aplican los Términos de Servicio de YouTube y las políticas de Google correspondientes.

Consulta la Política de Privacidad de Google.

7. Revocación de acceso

El usuario puede revisar o revocar el acceso concedido a SinContexto Control Center desde la página de permisos de seguridad de Google: Google Security Permissions .

Si el usuario revoca el acceso, SinContexto dejará de utilizar el token correspondiente. Los datos autorizados almacenados por la aplicación serán eliminados tan pronto como sea posible y, en cualquier caso, dentro de un plazo máximo de 7 días desde la solicitud o revocación cuando corresponda.

8. Solicitud de eliminación

El usuario puede solicitar la eliminación de los datos almacenados por SinContexto Control Center. El procedimiento se explica en nuestra página de Eliminación de Datos.

Eliminar datos del Control Center no elimina contenido o información almacenada directamente por YouTube. Para eliminar información de YouTube, el usuario debe utilizar YouTube o una aplicación autorizada que ofrezca esa función.

9. Seguridad

Adoptamos medidas razonables para proteger tokens, archivos y datos técnicos asociados a la integración. El acceso local al Control Center está limitado al entorno del propietario autorizado.

10. Cambios

Esta política puede actualizarse cuando cambien las funciones de la aplicación, los servicios conectados o los requisitos legales y de las plataformas.
