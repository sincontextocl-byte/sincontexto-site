Eliminación de Datos

Revocar el acceso a Google / YouTube

El usuario puede revocar el acceso concedido a SinContexto Control Center desde:

Google Security Permissions

Eliminar datos almacenados por SinContexto

El usuario puede solicitar la eliminación de los datos autorizados almacenados por SinContexto Control Center. La eliminación se realizará tan pronto como sea posible y, cuando corresponda conforme a las políticas de YouTube API Services, dentro de un máximo de 7 días.

Para el uso actual, SinContexto Control Center opera para el propietario autorizado del proyecto. La solicitud de eliminación puede realizarse mediante el canal de contacto público asociado a SinContexto.

Importante

Eliminar información almacenada por SinContexto Control Center no elimina videos, comentarios u otros datos almacenados directamente por YouTube. Esos datos deben eliminarse utilizando YouTube o una aplicación autorizada que permita esa operación.
