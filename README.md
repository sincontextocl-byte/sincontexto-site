# SinContexto Publisher

Sitio estático para GitHub Pages.

## Publicar
1. Crear un repositorio público, por ejemplo `sincontexto-site`.
2. Subir `index.html`, `privacy.html`, `terms.html` y `style.css` a la raíz.
3. Ir a Settings > Pages.
4. En Build and deployment elegir `Deploy from a branch`.
5. Branch: `main`, folder: `/ (root)`.
6. Guardar y esperar a que GitHub Pages publique el sitio.

URLs esperadas:
- https://TUUSUARIO.github.io/sincontexto-site/
- https://TUUSUARIO.github.io/sincontexto-site/privacy.html
- https://TUUSUARIO.github.io/sincontexto-site/terms.html
