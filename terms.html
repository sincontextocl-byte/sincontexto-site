Términos de Servicio

Última actualización: 24 de septiembre de 2026.

1. Servicio

SinContexto Control Center es una herramienta de producción, gestión, publicación y análisis de contenido.

2. Servicios de terceros

Algunas funciones utilizan servicios de terceros, incluyendo YouTube API Services y Google OAuth 2.0. El uso de dichas funciones también está sujeto a los términos y políticas aplicables de Google y YouTube.

3. Autorización

Las acciones conectadas a una cuenta de Google o YouTube requieren autorización expresa del usuario. El usuario mantiene el control sobre las cuentas conectadas y puede revocar el acceso.

4. Uso permitido

La aplicación debe utilizarse de conformidad con las leyes aplicables, los Términos de Servicio de YouTube, las políticas de YouTube API Services y las demás condiciones de las plataformas conectadas.

5. Disponibilidad

Las funciones pueden depender de APIs o servicios de terceros. Cambios, límites, revisiones o interrupciones de dichos servicios pueden afectar temporalmente algunas funciones.

6. Datos

El tratamiento de información se describe en nuestra Política de Privacidad.
